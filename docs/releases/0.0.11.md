# Specification 0.0.11: release notes

Specification [0.0.11](../../spec/0.0.11/archive-spec.md) installs the six
contract versions of [ADR 0113](../decisions/0113-editing-lead-sheets.md),
the lead-sheet editor, beside every 0.0.10 bundle with its exact bytes: <!-- lens: allow stale -->
melody version 2 and its sketches, form version 2's open repeats, form spans
version 2's passes and returns, meter layers version 3, the underlay, and
lead sheet version 2. Section D-19 states their rules. The layout is
`archive/2` and the core context and Entity kinds are 0.0.10's, so a 0.0.10 <!-- lens: allow stale -->
archive adopts it by the specification upgrade (D-15).

The release adds these six and removes none; every 0.0.10 bundle keeps its <!-- lens: allow stale -->
bytes. None of the new versions supersedes the one before it, and none is
current by kind or asserter.

## Profile rules

Two rules are new, and Door enforces both rather than refusing records that
cite them as pending:

- `x-archive-placed-items`: across a payload, in document order, the
  integers in each placed unit's `items` strictly increase, so words never
  share or cross notes.
- `x-archive-pass-lists`: every array a named path reaches is distinct
  ascending pass numbers, optionally followed by `last`, or `last` alone.

`x-archive-form-structure` is widened to check an open repeat's endings: one
last-time ending, one default, and the others of distinct ascending pass
numbers. A version 1 form means what it meant.

## Decided while implementing

These choices were made while building 0.0.11 and are for the operator to
confirm:

- **Meter layers version 3 stays the operator's.** ADR 0113's member
  contracts are melody 2, the underlay, form 2, form spans 2, and lead sheet
  2; meter layers 3 is not one, so World's circle and Door's member list do
  not name it. A later amendment may. The underlay's locators are checked
  against the document by the editor's adapter before it proposes, not by
  the relay.
- **A span's return is always true.** Form spans version 2's bundle makes a
  span's `return` const `true`; World now refuses `false` as Door does.
- **Played sections and bars, version 2.** `played_sections` and
  `played_bars` gain version 2, which reads form 2 and meter layers 3 and
  marks an entry open when it is played in the pass standing for an open
  repeat's further passes; version 1 answers as 0.0.10 served it. The <!-- lens: allow stale -->
  folded chart is the named view `folded_chart`.

## Moved again

The 0.0.10 notes moved three things to 0.0.11. None of them is built in <!-- lens: allow stale -->
0.0.11, so each moves again unless the operator decides otherwise:

- **The practice renderer and the exporters.** No renderer and no exporter
  program is installed; a practice render still answers
  `renderer_unknown`, and nothing is exported.
- **Forced alignment.** No aligner ships; the `timed-lyrics` proposer still
  answers `not_yet`. (`enrich align`, from ADR 0116, places a chart's
  untimed claims on machine beats; it does not align lyrics.)
- **Rhythm 5.** Downbeats from Beat This are not started; rhythm 4 stays,
  and the `written_rhythm` view still gives every note `bar: null` unless
  the reader asks for meter `layer: 1`.
